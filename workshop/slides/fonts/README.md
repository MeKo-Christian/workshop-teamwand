# Fonts

The deck and the handout use Proxima Nova (Regular, Light, Bold, Black). It is
a commercial font, so the files are not in this repository. To rebuild the
PDFs, put your licensed copies here:

- `proxima-nova-regular.ttf`
- `proxima-nova-light.otf`
- `proxima-nova-bold.otf`
- `proxima-nova-black.otf`

`just slides` points Typst at this folder (`TYPST_FONT_PATHS`). The committed
PDFs don't need them.
